# জাভায় সব সর্টিং অ্যালগরিদম (বাংলা ব্যাখ্যাসহ)

প্রতিটি অ্যালগরিদম আলাদা ক্লাসে আছে। প্রতিটি ক্লাসে `public static void sort(int[] arr)` মেথড আছে।

## চালানোর নিয়ম
```bash
javac -encoding UTF-8 *.java
java Main
```

## সারসংক্ষেপ

| অ্যালগরিদম | Best | Average | Worst | স্পেস | Stable |
|---|---|---|---|---|---|
| Bubble Sort | O(n) | O(n²) | O(n²) | O(1) | হ্যাঁ |
| Selection Sort | O(n²) | O(n²) | O(n²) | O(1) | না |
| Insertion Sort | O(n) | O(n²) | O(n²) | O(1) | হ্যাঁ |
| Shell Sort | O(n log n) | gap-নির্ভর | O(n²) | O(1) | না |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) | O(n) | হ্যাঁ |
| Quick Sort | O(n log n) | O(n log n) | O(n²) | O(log n) | না |
| Heap Sort | O(n log n) | O(n log n) | O(n log n) | O(1) | না |
| Counting Sort | O(n+k) | O(n+k) | O(n+k) | O(n+k) | হ্যাঁ |
| Radix Sort | O(d(n+b)) | O(d(n+b)) | O(d(n+b)) | O(n+b) | হ্যাঁ |
| Bucket Sort | O(n+k) | O(n+k) | O(n²) | O(n+k) | হ্যাঁ |
| Cocktail Shaker | O(n) | O(n²) | O(n²) | O(1) | হ্যাঁ |

**Stable মানে:** সমান মানের উপাদানগুলোর আগের আপেক্ষিক ক্রম sort-এর পরেও একই থাকে।

## বিস্তারিত ব্যাখ্যা

### ১. Bubble Sort
পাশাপাশি দুটি সংখ্যা তুলনা করা হয়। বাম সংখ্যা বড় হলে দুটির জায়গা বদল হয়। এভাবে প্রতি পাসে সবচেয়ে বড় সংখ্যা পানির বুদবুদের মতো শেষে চলে যায়। কোনো পাসে একটিও swap না হলে অ্যারে sorted, তাই থেমে যায়।
উদাহরণ: `[5,3,1]` → `[3,5,1]` → `[3,1,5]` → `[1,3,5]`।

### ২. Selection Sort
অ্যারের unsorted অংশ থেকে সবচেয়ে ছোট সংখ্যাটি খুঁজে বের করে unsorted অংশের প্রথম ঘরের সাথে বদল করা হয়। এতে swap কম লাগে, কিন্তু তুলনা সবসময় O(n²)।

### ৩. Insertion Sort
হাতে তাস সাজানোর মতো। বাম দিকের অংশ sorted ধরে নিয়ে, পরের সংখ্যাটি (key) নিয়ে বড় সংখ্যাগুলোকে ডানে সরিয়ে key-এর সঠিক জায়গা করা হয়। প্রায় sorted বা ছোট ডেটায় খুব ভালো।

### ৪. Shell Sort
Insertion Sort-এর উন্নত রূপ। প্রথমে দূরের উপাদানগুলোর মধ্যে (gap = n/2) তুলনা ও সাজানো হয়, তারপর gap অর্ধেক করা হয়, শেষে gap = 1 হলে সাধারণ insertion sort। এতে বড় সংখ্যাগুলো দ্রুত নিজের জায়গার কাছে পৌঁছায়।

### ৫. Merge Sort
"ভাগ করো ও জয় করো" (Divide & Conquer)। অ্যারেকে মাঝখান থেকে ভাগ করা হয় যতক্ষণ না একটি করে উপাদান থাকে। তারপর দুটি sorted অংশকে তুলনা করে একটি sorted অংশে merge করা হয়। সবসময় O(n log n), তবে বাড়তি O(n) মেমরি লাগে।

### ৬. Quick Sort
একটি pivot নেওয়া হয়। pivot-এর চেয়ে ছোটগুলো বামে ও বড়গুলো ডানে সাজানো হয় (partition)। pivot তার চূড়ান্ত জায়গায় বসে যায়। তারপর বাম ও ডান অংশে একই কাজ recursively চলে। বাস্তবে সবচেয়ে দ্রুতদের একটি। এই কোডে মাঝের উপাদানকে pivot ধরা হয়েছে যাতে sorted ইনপুটে worst case না হয়।

### ৭. Heap Sort
প্রথমে অ্যারেকে Max-Heap বানানো হয় (parent সবসময় child-এর চেয়ে বড়)। তখন root-ই সবচেয়ে বড়। root-কে শেষের উপাদানের সাথে বদল করে heap-এর আকার ১ কমিয়ে আবার heapify করা হয়। বাড়তি মেমরি লাগে না এবং worst case-ও O(n log n)।

### ৮. Counting Sort
তুলনা না করেই sort করে। প্রতিটি মান কতবার আছে তা `count` অ্যারেতে গুনে নেওয়া হয়, তারপর cumulative sum করে প্রতিটি মানের চূড়ান্ত অবস্থান বের করা হয়। মানের পরিসর (k) ছোট হলে অত্যন্ত দ্রুত।

### ৯. Radix Sort
সংখ্যাকে digit ধরে ধরে (একক → দশক → শতক...) counting sort দিয়ে সাজানো হয়। প্রতিটি ধাপ stable হওয়ায় শেষে পুরো অ্যারে sorted হয়। বেশি সংখ্যক পূর্ণসংখ্যা, যেমন ফোন নম্বর বা আইডি সাজাতে ভালো।

### ১০. Bucket Sort
মানের পরিসরকে কয়েকটি বাকেটে ভাগ করা হয়। প্রতিটি সংখ্যা তার উপযুক্ত বাকেটে যায়। প্রতিটি বাকেট আলাদাভাবে sort (এখানে insertion sort) করে সব জুড়ে দেওয়া হয়। ডেটা সমানভাবে ছড়ানো থাকলে দ্রুত।

### ১১. Cocktail Shaker Sort
Bubble Sort-এর দ্বিমুখী সংস্করণ। একবার বাম→ডান (বড়টা শেষে), পরের বার ডান→বাম (ছোটটা শুরুতে)। ছোট সংখ্যা অ্যারের শেষে থাকলে Bubble Sort-এর চেয়ে দ্রুত।

## কোনটি কখন ব্যবহার করবেন?
- **ছোট বা প্রায় sorted ডেটা:** Insertion Sort
- **সাধারণ ব্যবহার, দ্রুততম গড় গতি:** Quick Sort
- **গ্যারান্টিযুক্ত O(n log n) ও stable দরকার:** Merge Sort
- **বাড়তি মেমরি ছাড়া গ্যারান্টিযুক্ত O(n log n):** Heap Sort
- **ছোট পরিসরের পূর্ণসংখ্যা:** Counting Sort
- **শেখার জন্য:** Bubble, Selection Sort
